# Slow or Unresponsive Laptop

A slow laptop usually comes from too many running apps, low disk space, a pending
update, or — less often — malware. Work through the cheap, safe steps first and
escalate only if performance stays bad after them.

## Quick triage
Ask one clarifying detail: is it slow **all the time**, or only during something
specific like video calls or opening large files? The answer changes the steps.

## Step 1: Restart
A restart clears memory and finishes pending updates. Many "slow for days"
laptops are simply overdue for a reboot. Restart before anything else.

## Step 2: Free up disk space
Windows slows sharply when the system drive is nearly full.
1. Check free space on the C: drive.
2. Empty the Recycle Bin and clear the Downloads folder of large files.
3. Remove old local copies of videos or datasets that also live in the cloud.
Aim for at least 10% of the drive free.

## Step 3: Reduce startup and background apps
1. Open Task Manager and sort by CPU, then by Memory, to see what is heavy.
2. Close apps you are not using, especially extra browser windows with many tabs.
3. In Task Manager **Startup**, disable apps you do not need at login (keep
   security and VPN tools enabled).

## Step 4: Only slow during video calls
1. Close other apps and browser tabs before the call.
2. Turn off background blur/effects, which are CPU-heavy on older laptops.
3. Use a wired network or sit closer to the router.

## Step 5: Run the managed malware scan
If it is still slow, run the company-managed antivirus **Full Scan** from the
system tray icon. Do **not** download a third-party "cleaner" or "optimizer" —
those are unapproved and often unsafe.

## Safety notes
- Never install unapproved optimization or registry-cleaner tools.
- Never disable the managed antivirus to "speed things up".

## When to escalate
Escalate (see `escalation_policy.md`) if the laptop is still slow after a restart,
disk cleanup, and a clean malware scan; if the scan finds something it cannot
remove; or if the disk is failing (loud clicking, frequent freezes). Include the
model, age, and what makes it slow.
