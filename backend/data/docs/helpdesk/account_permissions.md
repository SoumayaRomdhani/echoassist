# Account Access & Permissions

Covers requesting access to shared drives, applications, and distribution lists.
Access is granted on **least privilege**: people get the minimum needed for their
role, and sensitive resources always require manager approval.

## How to request access
1. Identify the exact resource — the folder path, app name, or list, not just
   "the finance stuff".
2. Submit the request through the Access Portal at `access.acteek.local`, or ask
   the assistant to open a ticket with the details.
3. State the business reason and how long access is needed (permanent or a fixed
   project period).

## Approval flow
- Standard team resources: approved by your line manager.
- Sensitive resources (finance, HR, payroll, production systems): approved by the
  resource **owner** in addition to your manager.
- Access is reviewed every quarter; unused access is removed automatically.

## Requester identity
The assistant confirms who is asking and for which resource, but it does **not**
grant access itself and does **not** approve on a manager's behalf. Approvals
happen in the Access Portal by the named approver, leaving an audit trail.

## Common cases
- **New joiner missing an app:** confirm the role's standard access set was
  applied; request any extras through the portal.
- **Moved teams:** old access is not carried over by default — request the new
  team's resources and let the quarterly review retire the old ones.
- **Shared mailbox or distribution list:** request through the portal; the list
  owner approves.

## Safety notes
- Never grant access based only on "my manager said it's fine" — the manager
  approves it in the portal, on record.
- Never share your own credentials so someone else can use your access; that
  breaks least privilege and is a policy violation (see `security_policy.md`).

## When to escalate
Escalate (see `escalation_policy.md`) if the resource owner is unknown, if access
is urgently needed for an incident, or if a request would grant broad admin
rights — those get extra review.
