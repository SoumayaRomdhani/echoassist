# Hardware Requests & Replacements

Covers new equipment, replacements for broken or lost hardware, and accessories.
Standard equipment follows a role-based catalog; anything beyond it needs manager
approval.

## Standard equipment
Every employee is entitled to the standard kit for their role: a laptop, a
charger, and a headset. Remote employees also receive a home-office stipend for a
monitor, keyboard, and mouse. These do not need special approval — request them
through the Hardware Portal at `hardware.acteek.local`.

## Requesting a replacement
1. Describe the item and the problem (won't charge, cracked screen, dead battery).
2. For a laptop, first rule out a software cause (see `laptop_slow.md`) so a
   healthy machine is not replaced unnecessarily.
3. Submit the request in the portal, or ask the assistant to open a ticket with
   the model and the fault.
4. The Endpoint team confirms whether it is a repair or a swap and arranges it.

## Broken, lost, or stolen hardware
- **Broken:** request a repair or replacement; keep using a loaner if offered.
- **Lost or stolen:** report it immediately as a security event (see
  `security_policy.md`) so the device can be locked, *then* request a replacement.

## Accessories and non-standard requests
Items outside the standard catalog — a second monitor, a docking station, an
ergonomic chair, specialized peripherals — need line-manager approval with a
business reason, submitted through the portal.

## Timelines
- In-stock standard items: usually within a few business days.
- Non-standard or approval-gated items: depends on approval and stock.
- Urgent replacement blocking work: mark it high severity so it is expedited.

## Safety notes
- A lost or stolen device is a security event first and a hardware request second
  — report it so it can be locked before ordering a replacement.
- Do not buy equipment personally and expense it unless told to; use the portal.

## When to escalate
Escalate (see `escalation_policy.md`) if the request is blocking someone's core
work, if a device is lost or stolen (Security first), or if a non-standard item
needs approval the portal cannot route automatically.
